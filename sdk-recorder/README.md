# @flowr/sdk-recorder

FlowR recorder SDK — capture, edit, and replay guided walkthroughs in-page without the browser extension.

This directory contains built public distribution artifacts prepared from the private FlowR source repository for browser or CDN consumption.

Version: 0.1.0

Included files:
- `dist/index.js` — ESM bundle
- `dist/index.cjs` — CommonJS bundle
- `dist/index.d.ts` — TypeScript declarations

This package keeps `html-to-image` as an optional peer dependency for screenshot support. CDN consumers must provide that dependency separately when screenshots are enabled.
